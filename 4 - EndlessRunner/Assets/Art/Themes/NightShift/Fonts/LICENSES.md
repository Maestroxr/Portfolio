# Fonts of the Night Shift theme

- `BarlowCondensed-SemiBold.ttf`: Barlow Condensed by Jeremy Tribby, copyright 2017 The Barlow Project Authors
  (https://github.com/jpt/barlow). Licensed under the SIL Open Font License, Version 1.1 (`OFL.txt` next to it).
  Downloaded from the Google Fonts repository (https://github.com/google/fonts/tree/main/ofl/barlowcondensed).
  The art builder bakes it into `BarlowCondensed SDF.asset` (a static TextMesh Pro font atlas).

Everything else in this theme is generated by the game's own editor code (`Assets/Editor`).
